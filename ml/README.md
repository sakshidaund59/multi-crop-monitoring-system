# Machine Learning Workspace

This directory houses future ML assets, training code, satellite imagery pipelines, and disease/pest detection inference scripts for the Multi-Crop Monitoring System.

---

## Folder Structure

- `datasets/`: Raw and preprocessed crop imagery, satellite patches, and annotation datasets.
- `notebooks/`: Jupyter notebooks for exploratory data analysis (EDA), model prototyping, and validation experiments.
- `models/`: Exported model weights (`.pt`, `.onnx`, `.pth`) and evaluation metrics.
- `training/`: Modular Python scripts for model training, data loaders, and hyperparameter tuning.
- `inference/`: Preprocessing transformers and inference wrapper classes for deployment integration with the backend service.

---

*Note: Models and datasets will be populated during Phase 4 implementation.*
